## The last release before 1.0 adds features

From 0.11.0, new features wait until after 1.0. Every 0.11 release from here is a 1.0 candidate: fixes, checks and documents only.

## Security

- **Built with a patched Go.** Every release up to 0.10.11 was built with Go 1.25.0, which has 20 known vulnerabilities in code LANcast actually runs. They include HTTP/2 crashes and memory exhaustion, an unbounded `Range` header and a TLS handshake issue. This release is built with Go 1.26.10, with three libraries updated, and CI now fails a build that uses the wrong Go or reaches a known vulnerability.
- **A size limit on every request.** Sign-in, two-factor, passkey sign-in and first-run setup accepted a request body of any size before checking anything, so anyone who could reach the server could make it hold that much in memory. Every request is now limited to 1 MiB. Profile pictures, game saves, issue reports and plugins have their own larger limits.
- **The client's libraries are current.** React 19 and React Router 7.18.5, which fixes two moderate advisories, including an open redirect through a backslash in a link.
- **The parsers for files people bring are fuzzed in CI:** subtitles, playlists, NFO files and MilkDrop presets, alongside comics and pictures.

## A friend's film has real controls

Playing a film from a friend's shared library used to give you only play, the scrubber, volume and fullscreen. Now you also get:

- **Subtitles**, chosen from a list, starting with the film's default track. They also stay in time after a seek, which the old player got wrong.
- **An audio track**, when the film has more than one.
- **Back and forward 10 seconds**, on buttons or the ← → keys.
- **Skip intro and Skip credits.**

In Watch Together, the skips follow the host. Subtitles and audio are each viewer's own choice. Your friend's server needs this version too for the audio list and the skip buttons; everything else works with an older one.

## Music filed under the right names

- **More albums match MusicBrainz.** Titles made only of symbols (Justice's "✝"), names spaced differently ("Go A" and "Go_A") and stylized letters ("KoЯn") now match.
- **The right album artist.** Some files carry the standard album-artist tag and a broken extra one, such as "LBUM", and LANcast read the broken one. It now reads the standard tag.
- **Letter folders are not artists.** In a library sorted into folders like `G's\GIMS\`, untagged songs were filed under an artist called "G's". They're now filed under GIMS.
- **Albums you matched by hand stay matched.** A change in how LANcast reads your folders no longer moves tracks out of an album you chose a release for in Fix match. If you retag or move a file yourself, it's still filed by what it now says.

## Smaller changes

- **The desktop window opens maximized** every time, including when you bring it back from the tray.
- **Right-click any title on Home** for its menu, on every shelf and the spotlight.
- **The Settings category list scrolls on its own**, so its last entries are no longer hidden below the window.
- **Settings search highlights the setting it found** reliably, after opening its page.
- **A button in the player bar leaves the full-screen visualizer.** Before, the only ways out were the ← in the corner and the V and Esc keys.
- **The desktop window no longer offers the pop-out player.** A recent WebView2 update made it open an empty, oversized window. Browsers still have it.

## Live TV is off

Live TV is switched off on every server that installs this release, and its pages are hidden. It's being kept for work after 1.0. Your channels and guide are not deleted. To turn it back on, add `"live_tv": true` to the server's `config.json` and restart the LANcast service.

## Fixes

- A Windows playlist line rooted with no drive (`\Music\song.mp3`) was looked for on the C: drive. It's now looked for on the playlist's own drive.

## Updating

From 0.9.79 or later, use the in-app update. From anything older, run **`LANcast-Setup-0.11.0.exe`**.

**After updating, scan your music library once** (Settings › Libraries › your music library › Scan). That scan reads every song's tags again, so the album-artist and folder fixes reach the music you already have. It takes about as long as a first scan's tag pass. Then, to give albums that never matched another try with the new matching, press **Refresh unmatched** on the same library.

**This release changes the database.** Once 0.11.0 has started, an older version can't open the database, so update forward rather than reinstalling 0.10.11.
