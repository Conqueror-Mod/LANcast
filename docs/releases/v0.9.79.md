## Run the installer for this one

LANcast is now **one program**: `LANcast.exe` replaces `LANcast-Server.exe` and `LANcast-Client.exe`. In-app update can't make that change, so **download `LANcast-Setup-0.9.79.exe` below and run it**. Your library, settings, accounts and sign-ins are untouched.

If you use the in-app updater anyway, it will report that this release has no download it recognises. That's expected: it stops cleanly rather than installing half an update. After this release, in-app updates work as before.

## One program, one icon

- **A single LANcast.** The setup installs `LANcast.exe` and runs the server as a background service under it. It replaces the two Start-menu entries with one **LANcast** shortcut, and removes the old programs and the old tray's log.
- **The tray is always there while LANcast is open.** From it you can open LANcast, update your libraries, cancel an update in progress, check for updates, and choose whether LANcast starts when you sign in.
- **✕ hides the window; Exit closes LANcast.** The tray icon stays until you choose Exit. Exit never stops the server service: anyone else watching keeps watching.
- **Start at login opens quietly.** It puts the icon in the tray without opening a window. If you had this on, the setup carries it over to the new program.

## Cancel a library scan

- A scan in progress can now be cancelled, from the tray (**Cancel library update**) or with `POST /api/libraries/scan/cancel`.
- A cancelled scan keeps everything it had already found. **It never marks anything it hadn't reached as missing**, so cancelling partway through can't make part of your library look gone, and it never empties the trash.

## For people running LANcast by hand

- The command-line tools are now subcommands of the one program:
  - `LANcast.exe serve` (`lancast serve` on Linux) runs the server in the foreground.
  - `service install|start|stop`, `reset-auth` and `restore` are unchanged apart from the program name.
- The downloads are now named `LANcast_<version>_<os>_<arch>`. On Linux the binary is `lancast`.
- Firewall rules that open ports 8080 or 443 by **port** keep working. A rule that names `LANcast-Server.exe` as its program will need to point at `LANcast.exe`.
