## Fixes

- **Debug logging keeps about a day again.** Since 0.10.6, the log filled in about eleven hours. Most of it came from two things: each open LANcast window checking in every five seconds so your other devices can find it, and routers on the network asking every second for a kind of device LANcast isn't. Neither gets a line any more, and nor do the checks the Status pages and a paired server make on a timer, so the log now covers about 28 hours. Anything that's refused or goes wrong is still logged, and so is a TV that finds LANcast.

## Updating

From 0.9.79 or later, use the in-app update. From anything older, run **`LANcast-Setup-0.10.8.exe`**.

This release doesn't change the database, so 0.10.7 can be reinstalled over it.
