## LANcast 1.0.5

Up Next starts the next episode again.

## Fixed

- **Up Next's countdown runs.** When an episode's credits began, the Up Next card showed "Playing in 10" and stayed there, so the next episode never started on its own; only **Play now** moved on. The count now runs down while the episode plays and starts the next one at zero. Pausing still holds it, and **Cancel** still stops it.

## Updating

Use the in-app update (Settings, General), or run `LANcast-Setup-1.0.5.exe` over the top. The database is unchanged since 1.0.2, so going back to 1.0.4 is just reinstalling it.
