## Fixes

- **Finishing a film in a collection puts the franchise back on Home.** If you'd half-watched a later film in the collection more than a few weeks ago, finishing an earlier one left nothing from the franchise on Continue Watching or in the spotlight, though the screen after the film offered the next one. Continue Watching now offers that half-watched film, where you left it, as "Because you watched…" the film you just finished.
- **The tray's menu no longer signs the desktop app out.** When the app opens your server at its public name, so that passkeys work, the tray's **About**, **Update libraries** and **Check for updates** could load the server at `127.0.0.1` instead. That counts as a different site, so you were signed out there and only an authenticator code could sign you back in. The tray now opens pages at the same address the window uses.
- **Debug logging keeps far more history.** With **Debug logging** on, three requests every open window and phone repeats on a timer made up about four fifths of the server's log, so it held only a few hours. Those three no longer get a line each, so the log now goes back about a day rather than a few hours. Errors on them are still logged.

## Updating

From 0.9.79 or later, use the in-app update. From anything older, run **`LANcast-Setup-0.10.5.exe`**.

This release doesn't change the database, so 0.10.4 can be reinstalled over it.
