## Restore from Settings

- **Put a backup back without leaving LANcast.** Each backup in **Server › Backup & storage** has a **Restore** button. LANcast backs up the database as it is now, restarts, and puts the backup in its place. If you restored the wrong one, the backup it took first is right there in the same list.
- **Everyone is signed out** by a restore, on every device, and anything changed since that backup was taken is replaced.
- **If a restore fails, LANcast starts anyway** with the database it had, and the Backup page says what went wrong. It only tries once.
- On a setup where LANcast can't restart itself, the button isn't offered, and the `restore` command is shown as before.

## A backup before every update

- **When an update changes the database, LANcast backs it up first**, automatically. These show in the backup list as **"Before an update"**. The last three are kept, separately from your scheduled backups.

## Webhooks

- **Tell another program when something happens**, such as Home Assistant or a Discord channel. Add an address in **Server › Webhooks** and pick what it hears about: someone starts or stops watching, a library scan finishes, or a backup is taken.
- **Nothing is sent anywhere until you add a webhook.**
- **Viewing is only reported for people who turn it on themselves**, in **Your account › Privacy**. Nobody else can turn it on for you, administrators included. It reports a show's name, never which episode.
- Each message is signed with a secret that's shown once when you add the webhook, so the receiver can check it came from your server. Each webhook shows when it last sent something and whether that worked, and has a **Test** button.

## Metrics for Prometheus and Grafana

- **Your server's numbers in your own dashboards:** library sizes, scans and how long they took, conversions, backups, and errors. Nothing about who watches what.
- Make a token in **Status › Troubleshooting › Metrics** and give it to Prometheus. That token reads the metrics and nothing else.

## Reverse proxies

- **If you run Caddy or nginx in front of LANcast, add it in Server › Network › Trusted proxies.** Sign-in limits then apply to each visitor rather than to the proxy, and the account list on the sign-in page stays hidden from the internet. Before, everything arriving through a proxy on the same computer looked like it came from home.

## Fixes

- **Finishing an update restarts the server again** on setups that don't run LANcast as a Windows service. Since 0.9.79, the restart could bring back the LANcast window instead of the server.

## Updating

From 0.9.79 or later, use the in-app update. From anything older, run **`LANcast-Setup-0.9.96.exe`**.

**This update changes the database.** Once it has run, 0.9.95 and earlier can't open your library. LANcast backs the database up first ("Before an update" in Backup & storage), so going back to 0.9.95 means reinstalling it and restoring that backup with its `restore` command.
