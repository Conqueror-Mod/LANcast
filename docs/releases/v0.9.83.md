## Intros skip themselves

- **An episode's intro skips itself.** When an episode reaches its title sequence, LANcast skips it and shows **Intro skipped** with **Watch intro**, which takes you back to the start of the theme and lets it play. It only skips intros that already offered a Skip intro button. If you drag back into an intro, you get the button instead of a jump.
- **Your choice, on every device.** Turn it off in **This device › Player › Skip intros automatically**. The setting follows your account, so it applies everywhere you sign in. Credits still only get a button.

## Authorized devices

- **See everywhere you're signed in.** **Your account › Security** lists each device signed in as you: what it is ("LANcast app on Windows", "Chrome on Android"), when it was last used, and from where. **This device** marks the one you're using.
- **Sign one out, or all the others.** **Sign out** ends that device's session on the server at once. **Sign out every other device** leaves only the one you're using, if you ever see a device you don't recognise.
- **Administrators** see every account's devices in **Server › Users & access**.
- Devices that signed in before this update show without a name until they next sign in.

## Backups on a schedule

- **Backups happen by themselves, weekly.** **Server › Backup & storage** now has a backup schedule: never, daily, weekly, every two weeks or monthly. It keeps the newest four, and you can change how many. The first one is taken a few minutes after the update. Each is a copy of the database, about the size of yours, so four weekly backups take about four times that.
- **Your own backups are safe from it.** Only the backups the schedule took are ever deleted to keep the count. One you take yourself with **Take a backup** stays until you delete it. Each backup in the list says which it is.
- **Back up the database** is on **Status › Scheduled tasks**, with **Run now**.

## Fixes

- **"Keep for ever" now stays for ever.** Setting the audit log to keep entries for ever, or Continue Watching to never expire, went back to 90 days or 16 weeks after the server restarted. The next daily cleanup then deleted audit history you had asked to keep. Both settings now keep your choice.
- **Old sign-ins are cleared.** Sessions that had expired stopped working but were never removed from the database. They're cleared now.

## Updating

From 0.9.79 or later, the in-app update. From anything older, run **`LANcast-Setup-0.9.83.exe`**.

This update changes the database, so 0.9.82 can't open it afterwards. Your existing backups still restore.
