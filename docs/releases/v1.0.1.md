## LANcast 1.0.1

A fix for face grouping, and an easier way to put a screenshot in a problem report.

## Fixed

- **Face grouping and photo search download again.** Both features fetch the ONNX Runtime on first install, and LANcast fetched it from Microsoft's GitHub page for it. That page has gone, so on 1.0 the install stopped with a "404" on its last file. LANcast now takes the same runtime (1.29.0, signed by Microsoft) from Microsoft's NuGet package instead. The download is larger, about 148 MB instead of 76 MB, because that package holds every platform's copy. It happens once. Servers that already had face grouping or photo search installed were never affected.

## Improved

- **Paste screenshot in Report an issue.** A snip taken with Win+Shift+S is never saved as a file, so the only way to attach one was Ctrl+V, which nothing on screen mentioned. There's now a **Paste screenshot** button beside **Add pictures**. Ctrl+V anywhere in the form still works too.
- **The desktop window's clipboard permission now takes effect.** The window was meant to let LANcast read pictures off the clipboard without asking, but a fault in how it answered permission requests meant the setting never applied.

## Updating

Use the in-app update (Settings, General), or run `LANcast-Setup-1.0.1.exe` over the top. The database is unchanged since 1.0.0, so going back is just reinstalling 1.0.0.
