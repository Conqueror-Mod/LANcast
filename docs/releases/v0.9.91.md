## Visualizer colours

- **Visualizers now draw in the colour opposite the album cover's.** A warm cover gets a cool line and a cool cover gets a warm one, so the picture stands out from the background instead of blending into it. Before, an orange cover came out a dull, rusty red.
- **The colours are brighter**, so the line shows clearly against the dark background.
- This applies to Spectrum, Scope and Trails.

## Updating

From 0.9.79 or later, use the in-app update. From anything older, run **`LANcast-Setup-0.9.91.exe`**.

This update doesn't change the database, so you can go back to 0.9.90 if you need to.
