## Your own certificate

- **Use a certificate you already have.** If you have a certificate for your server, from your own certificate authority or a public one, give the paths to its certificate and key files in **Server › Network**. Other devices get it at once, with no restart.
- **Checked before it's saved.** If the files can't be read, don't belong together, or are out of date, the page says which, and nothing changes.
- **Renewals just work.** LANcast notices when the files change and switches to the new certificate without a restart, so a renewal tool can update them in place.
- **It can't stop the server.** If the certificate stops working, for example because it expired or a file moved, LANcast goes back to its own certificate and the page says why. Before, a bad certificate meant the server wouldn't start until you edited its settings file by hand.
- **The LANcast window on this PC keeps working.** It always uses LANcast's own certificate. Your public certificate, if you turned one on, keeps its name too.
- **Use LANcast's certificate** switches back.

## Change the port

- **Move the server to another port** in **Server › Network**. The server restarts, and the page you changed it from follows it to the new port.
- **If the new port doesn't work, it goes back by itself.** When the server doesn't answer on the new port within 30 seconds, LANcast puts the old port back and starts again, and the Network page says what happened.
- **Before you change it:** Windows Firewall has to allow the new port before other devices can reach it, and LANcast doesn't change your firewall itself. Friends' servers keep using the old port, so send them a new invite. Friends who reach you by a public name on port 443 aren't affected.
- Only the port changes. A server with no password still answers this computer only.
- Ports from 1024 to 65535 can be used, except 443 and 8200, which LANcast already uses for the public certificate and DLNA.

## Updating

From 0.9.79 or later, use the in-app update. From anything older, run **`LANcast-Setup-0.9.86.exe`**.

This update doesn't change the database, so you can go back to 0.9.85 if you need to. If you've changed the port, set it back to 8080 first, because 0.9.85 always looks for its server there.
